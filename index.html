      Architecture

      How two of my production systems fit together, from input to validated output.

      Document Q&A assistant

      Walmart · LangGraph · hybrid RAG

      A LangGraph router sends each question down the right path. Retrieval combines FAISS HNSW and BM25, then a cross-encoder reranks before the LLM answers with citations. RAGAS regression checks and human feedback keep faithfulness measured release to release.

      Demand forecasting pipeline

      BigBasket · gradient boosting · MLOps

      Sales history passes schema, null and range checks before feature engineering, so bad data stops before it reaches a model. XGBoost and LightGBM ensembles are tuned with Optuna, versioned in MLflow and served through FastAPI for batch and on-demand forecasts that feed inventory planning. Drift detection triggers automated retraining, and Docker with CI/CD makes each release repeatable.
